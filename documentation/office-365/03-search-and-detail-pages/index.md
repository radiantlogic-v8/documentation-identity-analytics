# Search and detail pages

This page describes the seven Office 365 search pages and their detail pages. The pages of each family are described in a dedicated page, structured in the same way.

## Overview

The Office 365 search pages are listed in the **Search** section of the left‑hand menu, after the standard search pages:

| **Menu entry**             | **Page title**                              | **Lists**                                                         |
| :------------------------- | :------------------------------------------ | :---------------------------------------------------------------- |
| SharePointOnline - Site    | Search SharePointOnline site collections    | SharePoint Online site collections                                |
| SharePointOnline - Content | Search SharePointOnline Sites/Lists/Items   | Site roots, lists and folders of SharePoint Online sites          |
| SharePointOnline - Group   | Search SharePoint Online groups             | SharePoint Online groups                                          |
| OneDrive - Share           | Search OneDrive shares                      | OneDrive drives                                                   |
| OneDrive - Content         | Search OneDrive files/folders               | Files and folders stored in OneDrive drives                       |
| ExchangeOnline - Mailbox   | Search ExchangeOnline mailboxes             | Exchange Online mailboxes (user and shared mailboxes)             |
| ExchangeOnline - Folder    | Search ExchangeOnline mailbox folders       | Folders of Exchange Online mailboxes                              |

The results of the Office 365 controls are presented in the **Office 365 reports** section of the left‑hand menu, once its dashboards have been shared. For more details, see [Office 365 reports](/office-365/07-dashboards-and-reports#office-365-reports).

All Office 365 search pages work like the other search pages: fill in the form (or click **Switch to free search** or **Switch to rule editor**), then click the magnifier icon to run the search. For more details, see [How to apply filters in search pages](/identity-analytics/enduser-guide/04-search-pages#how-to-apply-filters-in-search-pages).

At the bottom of each search page:

- Select **Compute KPI Trends** to display, next to each KPI, an arrow showing its trend since the previous timeslot.
- Click **Show Selected Entry Details** to open the detail page of the selected row.
- Click **Apply Analytics on Search Results** to run an analytic on the search results. For more details, see [How to apply analytics on search results](/identity-analytics/enduser-guide/04-search-pages#how-to-apply-analytics-on-search-results).
- Use the **…** menu to add or remove tags on all search results.

The Office 365 detail pages follow the same navigation pattern as the other detail pages (**Details**, **Access**, **Controls**, **Analytics** and **Decision history** tabs). The sections below describe what is specific to each workload. For a description of the tabs they share with the share and folder details pages, see [Share](/identity-analytics/enduser-guide/03-detail-pages#share) and [Folder](/identity-analytics/enduser-guide/03-detail-pages#folder).

The read, write, full control and view counts displayed on these pages are computed from the rights of each workload. The correspondence between the collected rights and these counts is described in [Office 365 ACLs](/office-365/05-acl-and-rights/#office-365-acls).

## Pages by family

The search pages and the detail pages of each family are described in the following pages:

- [SharePoint Online pages](/office-365/03-search-and-detail-pages/01-sharepoint-online): SharePoint Online site collections, content and groups.
- [OneDrive pages](/office-365/03-search-and-detail-pages/02-onedrive): OneDrive drives, files and folders.
- [Exchange Online pages](/office-365/03-search-and-detail-pages/03-exchange-online): Exchange Online mailboxes and mailbox folders.
